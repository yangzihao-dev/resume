## 一、项目概述

### 1.1 游戏定位
融合经典 FC 坦克大战 + 现代 roguelike 元素的 2D 俯视角射击游戏。玩家操控科技感坦克，在赛博朋克风格的战场中击毁敌军、收集装备、挑战 5 个巨型多阶段 Boss。

### 1.2 核心玩法融合
| 玩法来源 | 已实现融合点 |
|---------|-------------|
| 经典 FC 坦克大战 | 砖墙/钢墙/草地/水域/冰面地形、保卫己方基地（X 瓦片） |
| 《坦克世界》闪电战 | 4 种坦克类型：猎鹰(轻) / 暴风(中) / 堡垒(重) / 雷霆(火炮) |
| 《元气骑士》roguelike | 随机战斗/精英/宝箱房间 + 每关结束三选一 Buff 卡片（约 15 种） |
| 《弓箭传说》技能叠加 | 穿透弹 / 弹射弹 / 散射弹 / 燃烧弹 / 冰冻弹 / 多重射击 / 弹匣扩容 可叠加共存 |
| 现代手游 Boss 战 | 5 个巨型 Boss（钢铁巨蟹 / 磁暴机甲 / 熔岩巨兽 / 量子幽灵 / 天启坦克），每只 3~4 阶段行为机 + 弱点机制 + 环形/螺旋/扇形/追踪/激光弹幕 |

### 1.3 技术栈（Solo Builder 友好 · 零依赖）
```
渲染引擎:    HTML5 Canvas 2D（程序化绘制，无需任何图片素材）
语言:        原生 JavaScript (ES6+ 类/箭头/解构)
UI框架:      原生 DOM + CSS3（无 React/Vue）
样式:        CSS3 变量 + Flex + 霓虹发光/扫描线动画
音效:        Web Audio API 实时合成（射击/爆炸/拾取/Boss警报，无需音频文件）
数据存储:    localStorage（最高分 / 设置 / 错误日志）
打包:        无需打包。双交付形态：
             ① 多文件源码版：index.html + 6~8 个 .js + style.css
             ② 单文件整合版：坦克大战.html（CSS+JS 全内嵌，双击即玩，推荐普通用户）
```

> 💡 **为什么坚持原生？** Solo Builder 最重要的是「能跑起来 + 可调试」。原生方案：
> - 没有构建步骤，改完刷新即生效
> - 出问题直接 F12 定位到代码行
> - 任何机器任何浏览器都能跑，不挑环境

### 2.2 核心循环（Game Loop）
```js
requestAnimationFrame(loop) 驱动
├─ 输入采样  (Input.getState)   ← 每帧，标准化 WASD/方向/鼠标/触屏
├─ 逻辑更新  (Game.update, dt 毫秒，上限 50ms 防止切标签爆炸)
│   ├─ 玩家：移动 / 射击冷却 /  Buff 计时 / 燃烧/冰冻 DoT
│   ├─ 敌方 AI：追击型 / 狙击型(带红色预警线) / 爆破型 / 护盾型 / 治疗型
│   ├─ EliteEnemy 精英怪：黄色边框 + 召唤小兵/散射/旋转激光
│   ├─ Bullet：移动 + 穿透/弹射/燃烧/冰冻 状态机
│   ├─ Boss FSM：按 HP 百分比切阶段(0.6/0.3/0)，每阶段独立攻击模式
│   ├─ Pickup：碰撞玩家 → apply Buff
│   ├─ 碰撞解算：子弹-地图 / 子弹-实体 / 玩家-敌兵 / 玩家-道具
│   ├─ 地图瓦片破坏（砖墙 → 空地，钢墙仅爆破弹可毁）
│   └─ 进度判定：经典通关 / 无尽存活 / Roguelike 房间 / BossRush 轮次
├─ 渲染绘制  (Game.render)
│   ├─ 清屏 + 赛博网格背景（动画）
│   ├─ 屏幕震动（受伤/Boss 死亡/爆炸时 translate 抖动）
│   ├─ 图层顺序: 地图底 → 实体(敌方/子弹/道具) → 玩家 → 地图顶(草地遮挡) → 粒子
│   ├─ Boss 预警线 / 狙击红色瞄准线
│   └─ DOM HUD 刷新（HP 条 / 护盾 / 金币 / 波次 / 时间 / Boss 血条）
└─ 下一帧  requestAnimationFrame
```

```
d:\坦克大战\
```

## 三、核心玩法设计（已实际实现版本）

### 3.1 四种游戏模式（内部 mode 字符串严格对应）
| UI 显示模式 | 内部 mode 名 | 规则（已实现） |
|------------|-------------|---------------|
| 🔥 经典闯关 | `classic`    | 10 关递增难度；每关目标 = 消灭所有敌军 + 保护基地鹰标；关卡末尾三选一 Buff；第 3/5/7/9/10 关 Boss；最终关 Boss = 天启坦克 |
| ♾️ 无尽生存 | `survive`    | 敌军无限刷新，刷新间隔随时间缩短；每 45 秒 1 波 Boss；击杀给分；localStorage 存最高分榜 |
| 🎲  Roguelike 地牢 | `roguelike` | 随机房间类型：战斗/精英/宝箱；每个房间清完进入下一间，每次给 Buff；地图 procedural 生成瓦片布局 |
| 👑 Boss Rush | `bossrush`  | 连续挑战 5 个 Boss：钢铁巨蟹→磁暴机甲→熔岩巨兽→量子幽灵→天启坦克；击败每个 Boss 给升级；天启后全通关 |

> ⚠️ **注意代码和文档的严格对应**：实际实现内部模式字符串是 `classic / survive / roguelike / bossrush`（不是 endless / roguelite），调用 `game.startGame(mode, tankKey)` 时必须传这 4 个合法值，否则 `_initLevel` 的分支不匹配，会导致地图没生成、敌兵不刷新。

#### ① Collision 碰撞检测（AABB + 圆矩 + 子弹 vs 瓦片）
```js
const Collision = {
  rect(a, b) { // AABB 矩形相交（最常用，90% 碰撞用它）
    return a.x < b.x+b.w && a.x+a.w > b.x && a.y < b.y+b.h && a.y+a.h > b.y;
  },
  circleRect(cx, cy, cr, r) { // 圆 vs 矩形，用 clamp 最近点
    const nx = Math.max(r.x, Math.min(cx, r.x+r.w));
    const ny = Math.max(r.y, Math.min(cy, r.y+r.h));
    const dx=cx-nx, dy=cy-ny;
    return dx*dx+dy*dy <= cr*cr;
  },
  // 子弹 vs 瓦片网格：逐格扫描 + 反弹/穿透逻辑
  bulletMap(b, map) { return { hitTile:null, hitSide:null }; },
};
```

### 5.6 游戏主引擎 `Game` 类（game.js 核心）

> ⚠️ **史上最易踩坑 API：`start()` vs `startGame(mode, tankKey)`**（之前自动化测试花了 2 小时定位到的 bug）
> - `game.start()` —— **只是启动 RAF 主循环动画**，不改变 game.state，不创建任何实体！写在 constructor 末尾，只调 1 次
> - `game.startGame(mode, tankKey)` —— **真正开始一局游戏**：设置 this.mode / 重置分数 / 调用 `_initLevel` / `_switchScreen('game')` / state = 'playing'

```js
class Game {
  // ====== 生命周期 ======
  constructor() {
    // 1) 拿 canvas + ctx，设分辨率 960×640
    // 2) 实例化 input / sound / particles / map
    // 3) 加载 localStorage settings + highscore
    // 4) 绑定 UI DOM 按钮事件 (_bindUI)
    // 5) _renderTankCards（坦克选择卡片，代码里自动选第一张+自动点确认）
    // 6) _refreshHighScores
    // 7) this.start()   ← 只开 RAF，不开始游戏
  }
  start() { requestAnimationFrame(t => this.loop(t)); }

  loop(t) {
    const dt = Math.min(50, t - this.lastTime || 16); // 切 tab 回 dt 限幅
    this.lastTime = t;
    if (input.pause && (playing|paused)) togglePause();
    if (state === 'playing') this.update(dt);
    this.render();
    requestAnimationFrame(nt => this.loop(nt));
  }

  // ====== 关键：正式开始游戏 ======
  startGame(mode, tankKey) {            // mode ∈ {classic,survive,roguelike,bossrush}
    this.mode   = mode;
    this.level  = 1;
    this.score  = 0;
    this.kills  = 0;
    this.elapsed = 0;
    this.selectedTank = tankKey || 'medium';
    this.bullets = []; this.enemies = []; this.pickups = []; this.boss = null;
    this.bossSpawned = false;
    this._bossRushIndex = undefined;
    this._switchScreen('game');
    this._initLevel();     // 加载关卡地图 + 生成玩家 + 刷第一波敌军 / BossRush 调 _scheduleBoss
    this.state = 'playing';
  }

  _initLevel() {
    // 根据 mode 初始化地图:
    //   classic    → map.loadLevel(this.level - 1)
    //   roguelike  → map.generateRoguelikeRoom(random battle/elite/treasure)
    //   bossrush   → map.generateRoguelikeRoom('battle') + _bossRushIndex++
    //   survive    → map.loadLevel(0) 固定
    const ps = map.getPlayerSpawn();
    if (!this.player || this.level === 1)  this.player = new Player(ps.x, ps.y, selectedTank);
    else { player.x/y = ps; heal 40%; }
    this.bullets/enemies/pickups/boss = []/[]/[]/null;
    this.wave = 1;
    // 根据 mode 设置敌兵数量 / bossrush 调度第一个 Boss
    if (mode==='classic')   { maxWave = 5; enemiesLeftToSpawn = 18 + 3*level; enemySpawnCD = 800; }
    if (mode==='survive')   { maxWave = ∞; enemiesLeftToSpawn = ∞; surviveSpawnCD = 2500; }
    if (mode==='roguelike') { _setupRoguelikeRoom(); }
    if (mode==='bossrush')  { _scheduleBossForBossRush(); }
    _updateHUD(); _hideBossBar();
  }

  // ====== 每帧逻辑 ======
  update(dt) {
    elapsed += dt;
    player.update(dt, input, map, particles);
    if (input.fire) { const bs = player.tryFire(dt); bullets.push(...bs); sound.shoot(); particles.muzzle(); }

    遍历 bullets 更新 → 子弹出界 / 撞墙 brick destroy / bounce 反弹 / pierce 递减
    遍历 enemies 更新 → AI / takeDamage → hp<=0 调用 _onEnemyKilled()（给分/掉 pickup）
    遍历 pickups 更新 → 碰撞玩家 → apply / particles.pickup / sound.pickup
    if (boss) boss.update(dt, this)

    _resolveBulletCollisions();   // 子弹 vs 敌人 / 子弹 vs Boss（含弱点）/ 敌弹 vs 玩家
    _resolvePlayerEnemyTouch();   // 敌军碰撞玩家造成 40% dmg + 推开
    _updateEnemySpawning(dt);     // 按 mode 定时刷新兵
    _checkLevelProgress();        // 判断是否通关 / gameOver(false, reason)
    _updateHUD();                 // DOM HP 条 / 护盾 / 波次 / 时间 / Boss 血条
    particles.update(dt);
    _updateDamagePops(dt);        // 伤害浮动数字
    shakeTime -= dt;
  }

  // ====== 每帧绘制 ======
  render() {
    ctx.save();
    // 震屏 translate
    if (shakeTime > 0) ctx.translate(random*-intensity/2, ...);
    ctx.fillStyle = '#06081a';
    ctx.fillRect(0,0,w,h);
    drawCyberGridBackground(ctx, elapsed);  // 赛博网格背景（动画）
    map.draw(ctx);                          // 图层 1：瓦片底（草地先不画）
    bullets/enemies/pickups/player/boss → .draw(ctx);  // 图层 2：实体
    map.drawTop(ctx);                       // 图层 3：草地遮挡上层
    particles.draw(ctx);                    // 图层 4：粒子
    drawBossLaserWarning(ctx); drawSniperLaser(ctx);  // 图层 5：预警线
    drawDamagePops(ctx);
    ctx.restore();
  }

  // ====== 流程控制 ======
  _switchScreen(name)       // DOM .screen.active → 切换菜单/模式选择/坦克选择/游戏
  _renderModeCards()        // 4 张模式卡片 DOM（经典/无尽/roguelike/bossrush）
  _renderTankCards()        // 4 张坦克卡片 DOM（自动选 medium + 自动点"确认出击"，代码里写死自动）
  _bindUI()                 // 所有按钮 data-action 映射
  _updateHUD()              // 刷新 DOM HUD（每帧 1 次）
  _spawnBoss(bossKey)       // 从屏幕顶部飞入 + 震动 + sound.bossWarn() + 显示 Boss 血条
  _nextLevel()              // level++ → 或 Roguelike 下一间
  _showBuffSelect(title)    // 从 BUFFS 池抽 3 张 → state = 'buff-select'
  _gameOver(win, reason)    // state = 'gameover'/'victory'，写 localStorage 最高分
  shake(intensity, duration){ shakeTime = max；shakeIntensity = max }
  togglePause()             { state playing⇄paused，DOM overlay }
}
```

## 七、关键实现细节提示（已踩坑经验）

### 7.1 坦克的程序化绘制（不用图片，科技感拉满）
Player.draw(ctx) 内实现步骤：
1. 履带：两条宽圆角矩形，深灰 + 每 4px 画 1px 履带节黑线
2. 车身：圆角矩形 `roundRect`，霓虹色描边 2px（`shadowBlur = 14` + `shadowColor = color`），内部线性渐变
3. 炮塔：六边形（`moveTo + lineTo ×6`），白色描边，紫色发光
4. 炮管：随 angle 旋转的细长矩形，末端加粗（炮口）
5. 护盾：`shieldCount > 0` 时，画一个旋转的六边形能量罩（纯线框 + 半透明蓝，`rotate(elapsed/600)`）
6. 燃烧 / 冰冻叠加：`shadowColor` 换橙/蓝，再叠一层 crackle 纹理

### 7.2 Boss 多阶段行为机模板（复制粘贴改数值即可）
```
on boss.update(dt, game):
  hpRatio = this.hp / this.maxHp
  // 切阶段
  if (phase===1 && hpRatio<0.6) enterPhase(2)
  if (phase===2 && hpRatio<0.3) enterPhase(3)
  if (phase===3 && hpRatio<=0)  dead

  // 每阶段独立选行为
  attackTimer -= dt
  if (attackTimer <= 0):
    switch [bossKey, phase]:
      crab, phase1:   → 双炮管交替 fire(bullets[fan])
      crab, phase2:   → ringBullets(8) + 召唤小兵 2
      crab, phase3:   → 速度 x2 + homingBullet ×3
      magneto, any:   → 周期 EMP（game.state = 'frozen-shoot' 1.5s）
      lava, phase2:   → spiralBullets(phase=elapsed/50)
      ghost, phase1:  → 周期 teleport(x,y) + set invisible=true
      apoc, phase3:   → 充能 2s → laserBullet(玩家方向, 长=960, dmg=9999)
    attackTimer = 1200ms~2500ms 随 phase 递减
```

### 7.3 子弹穿透/弹射/燃烧/冰冻的叠加实现
- **穿透 pierce**：bullet._hitSet = new Set()，命中敌人时 `if (hitSet.has(e)) return;`，否则 `hitSet.add(e); pierce--; if (pierce<0) dead=true`。避免一颗子弹连续多次打同一个敌人。
- **弹射 bounce**：bulletMap 返回 hitSide='H' 则 `vy = -vy`；`'V'` 则 `vx = -vx`；`bounce--`。每次 bounce 后 `position += vx*2; vy*2` 避免卡在墙里反复弹。
- **燃烧 fire**：命中后 `enemy.applyBurn(4 + dmg*0.1 秒)`，敌人 `_burnUntil` 前每帧扣 `0.6 × dmg/sec`，画橙色 shadowBlur。
- **冰冻 ice**：命中后 `enemy.applySlow(3s)`，速度 ×0.5，画蓝色裂纹覆盖层。
- **溅射 splash**：player 雷霆 + 爆破弹，命中后遍历敌人 `if (distance < radius) e.takeDamage(dmg * (1-d/r))`。

### 7.4 ES6 import/export 与 单文件整合冲突的处理
开发阶段用多文件的 ES6 import/export 便于组织；最终交付必须转单文件。整合步骤：
1. 把所有 `export const` / `export class` → 去掉 `export`，变成全局 `const` / `class`
2. 把其他文件的 `import { X } from './y.js'` → 直接删除（因为已经是全局名字空间）
3. 按依赖顺序 `<script>` 粘贴（CONFIG → 工具类 → 实体 → Game）
4. **测试**：双击文件:// 直接打开，F12 无 ERRORS（任何一个 undefined 引用说明粘贴顺序错了）

### 7.5 性能优化（已落实）
1. **实体上限**：敌军 ≤ 25，子弹 ≤ 150，超过就停刷新兵（`enemies.length >= MAX_ON_SCREEN`）
2. **地图缓存**：`GameMap.offscreen` 离屏 canvas，瓦片没改时每帧直接 `drawImage`（≈ O(1)），砖墙被毁才 `invalidateCache()` 重绘
3. **粒子上限**：`ParticleSystem.pool.length > 400` 时新粒子直接丢弃，不影响逻辑
4. **AI 节流**：Enemy AI 决策（选目标、找方向）每 120ms 算一次（`_nextAiAt`），不用每帧都算
5. **碰撞粗筛**：AABB 之前先算距离平方，超过 `(size1+size2+20)^2` 的直接跳过精算
6. **Canvas 尺寸固定 960×640**：避免 HiDPI 每帧 drawImage 放大造成 CPU 飙升（移动端 CSS `max-width: 100%` 缩放下游 GPU 处理）
